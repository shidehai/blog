# 在青山写作

打开后台域名，用唯一所有者密码进入。内容列表可以搜索标题或固定地址，按草稿、已发布、已归档筛选；新建时选择文章、教程、随记或专题。

## 写作与保存

输入标题，在 Markdown 编辑区写正文。宽屏可以对照预览，手机切换编辑与预览。正文支持中文、代码高亮与复制、表格、列表、引用及提示块。预览与博客共用语法和正文样式。

修改会自动保存；顶部显示等待保存、保存中、已保存或保存失败。“立即保存”可以主动提交。成功保存的草稿可在刷新后继续编辑。多个标签页编辑同一篇文章时，旧版本保存会提示冲突并保留当前文字：可将当前文字另存为新草稿，也可明确确认后载入最新版本。

## 插图与封面

- 用工具栏上传按钮选择图片，或把图片拖进正文，也可以直接粘贴截图。
- 从媒体库选图时可填写替代文本，然后自动插入光标所在位置。
- 上传过程中继续输入，插入位置会随文字移动；失败可以重试或移除失败任务。完成图片任务后才能发布。
- 正文图保持原始比例；文章属性中的封面用作列表缩略图，可独立更换。

支持 PNG、JPEG、WebP、GIF、AVIF，单张最多 20 MiB。上传后图片先留在私有后台，只有当前已发布正文、封面或已保存站点头像引用的图片可公开访问。媒体库中的“允许文章发布时公开此图片”是许可开关，不会单独把未引用图片上线；关闭会立即禁止公开读取。历史记录及原文件保留，首版不自动清理媒体。

## 发布与撤回

文章属性可设置固定地址、摘要、分类、标签、系列、专题关系、封面、精选和发布时间。发布时间留空时采用首次发布时间；这里是文章日期，不是定时发布功能。

点击“发布文章”或“发布更新”会先保存当前草稿，再原子切换线上版本。成功后出现“已发布，博客已更新”和“查看文章”。新请求立即可见，不用等整站构建。已有打开的博客在刷新、导航、前进/后退或重新聚焦时核验内容版本；版本变化会重新载入页面。

如果发布网络中断，点击“确认发布结果”核对同一次操作。结果未明时编辑暂时锁定，避免丢失已确认的发布版本。

继续编辑已发布文章只改变工作草稿。历史版本可预览并“恢复为草稿”，显式再发布后才改变线上内容。归档会撤回公开文章并保留正文、地址和历史；之后可重新发布。改固定地址后，历史公开地址跳到当前规范地址。

随记和专题保存在个人后台，没有首版公开频道。分类定义与站点资料的保存会直接更新公开显示。

## 导出与找回访问

站点资料页可下载结构化内容 JSON。包含实际图片、Markdown 和校验清单的完整导出/恢复请使用 [恢复说明](operations/backup-restore.md) 中的 CLI。内容导出不含所有者密码与会话。

忘记密码时，在服务器使用 owner 管理命令重置；旧会话会失效。说明见 [后台初始化](../author-cms/README.md)。
