# 青山写作 · 界面说明

Surface mode: Operate. The owner's success is writing, finding a picture and deliberately publishing a saved draft. Public reading identity stays in the existing frontend DESIGN.md; this brief owns only the private CMS.

A warm paper canvas (#f8f7f3/#fffefa), sage navigation (#f0f1ea) and restrained vermilion actions (#a63d2c) support a calm writing room. Self-hosted Inter handles controls, Noto Serif SC titles, and monospace the Markdown source. Text, icons and labels carry every state as well as color.

Content lists are readable rows with small covers; editor prioritizes title and text, with attributes behind a clear control. Desktop source/preview can sit together; phone editing/preview switch without horizontal scrolling. Body pictures keep their ratio; cover thumbnails may crop. Dialogs use native dialog semantics, clear close controls and consistent focus. Closed mobile navigation is inert; long titles grow; uploads and unresolved publication protect pending work.

Verification uses real Chinese long titles, horizontal/portrait pictures, code and tables at desktop and 390px mobile width. One batched design correction and one confirmation pass are the polishing ceiling. Technical failures can still be fixed with focused regression checks.
